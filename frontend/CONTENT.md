# Suncly website — content source

Every claim on the site and in the workspace traces to one of the sources below.
Components import copy from `lib/content.ts`, status words from `lib/capabilities.ts`
and `lib/launch.ts`, and sample data from `lib/sample/`. Nothing is improvised in JSX.
Edit this file first, then the TypeScript.

Rebuilt 2026-10-05 (the "Daylight" redesign). Where the brief and the repository
disagreed, the repository won and the disagreement is listed in `REDESIGN_PLAN.md` §2.

## Status words

Three public words, from `lib/capabilities.ts`: **Available** (a visitor can do it today;
a limit, where one exists, is stated beside it), **Pilot** (exists and is used with pilots;
the CLI as a whole and programme states), **Planned** (not implemented; future tense; no
date). Launch state comes from `lib/launch.ts`: repository public (`RUN`: `git ls-remote`
succeeds without credentials), CLI in pilot, HTTP API planned, billing not live,
certification not open, no coding agent verified, trade mark unregistered (™).
