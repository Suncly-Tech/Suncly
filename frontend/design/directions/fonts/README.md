# Draft fonts

Full variable TTFs for the art-direction drafts only. Newsreader, Figtree and Hanken
Grotesk were fetched on 2026-10-05 from the google/fonts repository (SIL Open Font
Licence 1.1). JetBrains Mono is the site's existing latin subset. The chosen direction
gets latin subsets as woff2 through `next/font/local`; these TTFs are not shipped.
